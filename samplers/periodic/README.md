# Periodic sampler

Closed multi-twist / Teichmüller geodesics on the X(1,1) prototype.

Source of the 20 exact 2:1 orbits: sibling repo
[prym-omega-ed6-h1plus](https://github.com/HeywoodGeblomi/prym-omega-ed6-h1plus)
(`data/x11_invariant_21_hits.json`, `data/multi_geodesic_spectra.json`).

These spectra are **path-local**. They are reported for contrast with the
generic sampler. They are not the measure average.

Every estimate must carry a QR / interval error bar before it is recorded
in a deliverable table.
